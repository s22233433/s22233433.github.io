# AI 入門六課 SEO 與學習銜接設計

**目標：** 在不拉長課程、不改變既有 URL 與版型的前提下，讓六堂 AI 入門課更容易被理解、分享與搜尋。

## 範圍

- 保留六堂課的現有主體、80 分鐘定位、圖片、影片與導覽。
- 每堂課補一個短的「完成後你能做什麼」成果句，以及一個指向下一個合理步驟的銜接句。
- 第 1 至第 6 課只補各自缺少的核心判斷，避免新增理論段落。
- 課程目錄與每堂課加入一致的 JSON-LD 結構化資料：`Course`、`FAQPage`、`BreadcrumbList`。
- 補齊各頁 Twitter 分享標題、描述與圖片；維持既有 canonical 與 Open Graph URL。

## 內容調整

| 課程 | 最小補強 |
| --- | --- |
| 第 1 課 | 說明成果是完成可驗收任務，不是只會問 AI；導向第 2 課。 |
| 第 2 課 | 加入成功標準例句，導向第 3 課的流程拆解。 |
| 第 3 課 | 明確分開 Agent、半自動與全自動，導向第 4 或第 5 課。 |
| 第 4 課 | 強化驗收與變更範圍，導向第 5 課。 |
| 第 5 課 | 說明它承接第 3 課、而第 6 課才處理模板複用。 |
| 第 6 課 | 說明案例庫只供拆解與改造；以「大型案例庫」取代易過時的數量承諾。 |

## 結構化資料設計

- 每堂課的 `Course` 使用正式標題、描述、正規網址、圖片、閱讀時間與課程目錄網址。
- `FAQPage` 從既有 `<details>` 讀取，JSON-LD 內容與頁面可見文字保持一致。
- `BreadcrumbList` 固定為首頁、My Tools、AI 入門課程目錄、目前課程。
- 課程目錄以 `ItemList` 列出六堂課及其 URL。

## 驗證

- HTML 解析成功，六頁都有唯一 title、description、canonical、JSON-LD、Twitter metadata。
- JSON-LD 可被 JSON 解析，FAQ 問答數量與頁面 `<details>` 一致。
- 所有課程與目錄內連結均指向存在的本機頁面或安全的外部網址。
- 檢查 Git diff，並在 GitHub Pages 建置完成後確認六個公開 URL 回應正常。
