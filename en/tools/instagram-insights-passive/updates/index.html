How should you read these version labels?

Chrome Web Store public version means the version installable from the Store today. The Store-installable public version is v0.7.18; the latest version documented on this page is v0.7.25. Versions v0.7.19–v0.7.25 cover continued development or administrator-provided features and are not general Chrome Web Store downloads. Available values always depend on what the platform has actually loaded.
