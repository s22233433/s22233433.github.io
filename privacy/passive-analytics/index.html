Instagram Insights (Passive) 隱私權政策

生效日期：2026 年 7 月 19 日

本政策說明 Instagram Insights (Passive) Chrome 擴充功能如何處理資料。此擴充功能由榛菓行銷（ZhenguoCool）提供。

資料處理方式

擴充功能只在使用者主動開啟的 Instagram 個人主頁上運作。它會被動處理該頁面已經載入的內容與既有網路回應，將近期貼文和 Reels 的必要統計欄位（例如按讚、留言、觀看與發布日期）整理成分析面板與報告。

本機儲存

分析偏好、面板設定與已整理的貼文統計快取只會儲存在使用者自己的瀏覽器中，使用 Chrome storage 與 IndexedDB 保存。這讓使用者重新整理、切換頁面或再次開啟擴充功能時可查看既有結果，並減少重複處理。

不會收集或傳送的資料

  • 不會將分析資料、網站內容或個人資料傳送到榛菓行銷或任何第三方伺服器。
  • 不會讀取、保存或上傳 Cookie、Authorization、CSRF Token、Session、密碼或其他登入憑證。
  • 不會主動構造、重放或傳送 Instagram 的未公開 API 請求。
  • 不會出售資料、用於廣告追蹤，或與第三方分享資料。

使用者控制

使用者可以在擴充功能內清除本機分析資料，也可以隨時在 Chrome 中停用或移除擴充功能。移除擴充功能後，Chrome 會依其瀏覽器資料管理機制處理相關本機儲存資料。

政策更新與聯絡方式

若功能或資料處理方式有重大變更，本頁會同步更新。若對本政策有疑問，請聯絡 weiting@zhenguocool.com。
