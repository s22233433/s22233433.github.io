CHROME EXTENSION · LOCAL-FIRST SOCIAL ANALYTICS

Kソーシャル分析 ｜ Passive Analytics

パフォーマンスを理解し、
データは手元に残す。

自分で開いた Instagram または TikTok のプロフィールページで、すでに読み込まれた公開コンテンツを Chrome 内に整理します。直近の成果、人気投稿、履歴推移、複数アカウント比較まで確認できます。

START IN FOUR STEPS

ページを読み込み、
あとはツールに整理を任せる。

パスワード、投稿リスト、API キーを出力する必要はありません。現在開いているページですでに読み込まれたデータだけを扱います。

  1. 01
    プロフィールを開く

    調べたい Instagram または TikTok のアカウントを開きます。

  2. 02
    分析範囲を選ぶ

    直近の投稿数または日数で開始します。

  3. 03
    パネルとレポートを見る

    KPI、人気コンテンツ、詳細な範囲計算を確認します。

  4. 04
    保存、比較、エクスポート

    ローカルのスナップショットを残し、アカウントを比較、または出力します。

REPORTS · COMPARE

レポートも比較も、
すべてブラウザ内で完結。

設定可能な範囲でコンテンツの推移を読み、ローカルに保存済みのアカウントを同じ表で比較できます。例のデータはすべて架空です。

ONE EXTENSION · TWO PLATFORMS

いま見ている内容から、
あとで振り返れる判断材料へ。

2 つのプラットフォームで同じ操作感を提供しながら、データモデルとローカルデータベースは分けて保持します。

  • 出力ファイル名のカスタマイズ

  • データ鮮度とサンプル差の通知
  • お気に入りを一元管理

  • キャッシュ上限を調整
  • JSON バックアップと復元

PRIVACY & DATA BOUNDARY

データ仲介サービスでも、
アカウント自動化でもありません。

行うこと 現在のページで読み込まれたレスポンス、ページ状態、可視 DOM を受動的に処理し、ローカルで計算・保存します。

行わないこと Cookie、トークン、セッション、パスワードを読み取り、保存、送信しません。非公開 API を構築、呼び出し、再生しません。

保存先 Instagram と TikTok のデータは別々のローカルデータベースに保存され、エクスポート、インポート、削除が可能です。
