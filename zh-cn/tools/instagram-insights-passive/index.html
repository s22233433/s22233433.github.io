START IN FOUR STEPS

先让页面加载，
再由工具整理。

无需导出账号密码、贴文清单或 API Key。工具只处理你当前打开页面已加载的数据。

  1. 01
    打开个人页面

    前往想研究的 Instagram、TikTok 或 Threads 账号主页。

  2. 02
    选择分析范围

    按近期篇数或天数开始分析。

  3. 03
    查看面板与报告

    从 KPI、热门内容到可配置范围的详细报告。

  4. 04
    保存、比较或导出

    在本机保存快照、比较账号，或导出数据。

REPORTS · COMPARE

报告与比较，
都在你的浏览器里完成。

用可配置的范围阅读内容趋势，或将已保存账号放入同一张比较表；示意数据均为虚构。

V0.7 · PROJECT WORKSPACE

把创作者名单，
变成可追踪的项目工作台。

同一位 Instagram、TikTok 或 Threads 创作者可加入多个客户、活动或提案项目；分类与合作信息都保留在浏览器本机。

  1. 01
    集中管理合作信息

    在项目中查看备注、Email、LINE、WhatsApp、WeChat 与每个项目独立的合作进度。

  2. 02
    从工作摘要安排下一步

    快速找出缺联络资料、资料过期、待更新或需要注意的创作者，再依筛选范围批量刷新、比较、导出或备份。

ONE EXTENSION · THREE PLATFORMS

从当前内容，
到可回看的决策线索。

三个平台共享同一种使用方式，但各自的数据模型与本机数据库保持分离。

◎

页内数据分析

近期篇数／天数、KPI、热门内容、发文频率与最后发文日期。

  • 粉丝与账号内容总数
  • 赞、评论、观看、ER、ERR
  • Instagram 协作贴文标记
↗

详细报告与导出

按五个可自定义的时间／篇数范围重新计算。

  • 趋势、热门内容、逐篇明细
  • CSV、JSON、Excel、浏览器 PDF
  • 可自定义导出文件名
◌

历史与多账号比较

保存分析快照，回看趋势，并比较本机已保存账号。

  • 历史范围筛选
  • 数据过期与样本提醒
  • 收藏账号统一管理
⌘

设置、备份与恢复

将分析范围、KPI、热门内容与缓存上限集中设置。

  • 自定义快捷范围
  • 可调整缓存上限
  • JSON 备份与恢复

PRIVACY & DATA BOUNDARY

不是数据搬运服务，
也不是自动化账号。

会做的事 被动处理当前页面已加载的响应、页面状态与可见 DOM，并在本机计算与保存。

不会做的事 不读取、保存或上传 Cookie、Token、Session 或密码；不构建、调用或重放未公开 API。

数据保存 Instagram、TikTok 与 Threads 分别保存在本机数据库，可导出、导入或自行清除。
