AI 入門第三課

讓 AI 不只回答，而是完成工作。

ChatGPT 是聊天介面。真正有價值的是把重複工作拆成流程，讓 AI 一步一步協助你完成。

視覺速記

這堂課要解決什麼問題

從聊天變成流程

不是問一句拿答案，而是把一件重複工作拆成可以交辦、檢查、重跑的步驟。

知道什麼能自動化

重複性高、格式固定、風險可檢查的任務，才適合先交給 AI。

避免一開始做太大

第一個 Agent 不要追求全自動。先做最小可行流程，再慢慢加。

課前準備

請她列 3 件重複工作

例如整理新聞、整理資料夾、回覆表單、每週報告、固定格式的訊息。

選一件低風險任務

不要第一堂就碰金流、合約、醫療、公司機密或需要真人判斷的高風險流程。

AI 助理與 AI Agent 的差別

AI 助理

你問一句，它回一句。適合寫作、整理想法、改語氣、做第一版草稿。

AI Agent

你給目標和流程，它可以分步驟處理資料、使用工具、產出結果，再讓你檢查。

什麼任務適合交給 AI

重複性高

一週做三次以上，或每次步驟都差不多。

流程固定

可以寫出第一步、第二步、第三步。

輸入輸出清楚

知道要給什麼資料，也知道最後要得到什麼。

風險可檢查

AI 做完後，人可以快速檢查是否合理。

格式可重複

例如表格、摘要、信件、分類、檔名規則。

失敗成本低

做錯了可以重跑，不會造成付款、刪檔或重大誤判。

什麼任務不要一開始自動化

  • 高風險決策
  • 資料來源不穩
  • 判斷標準很模糊
  • 牽涉金流或隱私
  • 做錯無法復原
  • 還沒有人工流程可參考

把工作拆成流程

輸入

AI 需要哪些資料？檔案、表單、網址、文字、資料夾。

處理

要分類、摘要、改寫、比對、整理，還是產生回覆？

檢查

哪些地方必須人工確認？哪些錯誤最危險？

輸出

最後要得到什麼？表格、信件、報告、檔案、待辦清單。

例外

如果資料缺漏、格式錯、AI 不確定，要怎麼停下來問人？

第一版

先做半自動流程，人確認後再進入下一步。

工具地圖

ChatGPT

文字、想法、摘要、改寫。適合先把流程想清楚。

Codex Desktop

本機檔案、HTML、小工具、資料整理。適合有檔案要處理時。

n8n

偏進階，可自架或雲端，把不同服務串成流程。

Make

視覺化流程工具，適合把表單、信件、表格接起來。

Zapier

上手快，適合常見 SaaS 之間的簡單自動化。

MCP

讓 AI 連到工具或資料來源。新手先知道概念，不急著配置。

可複製 Agent 規劃模板

我想把這件重複工作交給 AI 協助：[工作名稱]。 目前流程是： 1. [第一步] 2. [第二步] 3. [第三步] 請你幫我判斷： - 哪些步驟適合 AI 做 - 哪些步驟需要人工確認 - 需要哪些輸入資料 - 最後應該輸出什麼結果 - 這個流程有哪些風險 - 如果要做成 Codex / n8n / Make 自動化，第一版最小可行流程是什麼

FAQ

Agent 是不是一定要寫程式？

不是。第一步是流程設計。ChatGPT 也可以先幫你把流程拆清楚。

什麼時候用 Codex？

當任務牽涉本機檔案、HTML、小工具或資料整理時，Codex 比純聊天更合適。

什麼時候用 n8n、Make、Zapier？

當流程需要串表單、信件、表格或多個雲端服務時，再考慮這些自動化工具。
