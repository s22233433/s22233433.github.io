本版聚焦程式碼最佳化與維護效率：收斂真正平台無關的純邏輯，讓相同的計算與頁面流程不再各自維護；不新增平台請求、不改被動監聽、本機資料庫或統計公式。

將 Threads 納入第三個獨立的本機被動分析平台，並持續補強已載入資料的觀看、社群連結與頭像處理；未知值維持 N/A，不推算也不主動請求平台 API。

  • 只整理 Threads 頁面已載入的 fetch／XHR 回應、hydration 與可見 DOM，提供本機快取、浮窗、詳細報告、歷史快照、平台內比較、收藏、備註、背景刷新與備份／還原。Threads 使用獨立 IndexedDB，避免三平台資料互相混淆。
  • 貼文保存已提供的讚、回覆、轉發、引用、轉分享、文字與地點等資料。可見「最近瀏覽次數」只會在沒有任何單篇觀看時補到浮窗總觀看；平均觀看與 ERR 保持 N/A，不會將帳號級數字當成單篇樣本。

  • 頭像優先使用已成功保存的本機 Blob；若圖片受跨來源限制無法轉存，會回退 HTTPS URL 並使用 no-referrer。修正 Instagram 新 Blob 成功後未即時更新舊 URL 的競態，背景刷新會同步最新頭像與帳號欄位。
