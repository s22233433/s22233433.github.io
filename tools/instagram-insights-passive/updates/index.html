最新功能版本v0.5.13

桌面載入版已驗證 · Chrome 商店公開版本仍為 v0.5.10

前往 Chrome 商店安裝 ↗
最新功能版本v0.5.132026.07

設定頁新增本機資料用量總覽

資料分頁新增只讀儲存儀表，讓使用者直接知道擴充功能目前保存了哪些資料，以及大約使用了多少本機空間。

  • 顯示 IndexedDB 與 chrome.storage.local 估算用量、瀏覽器配額與 Storage 項目數。
  • 分別統計 Instagram／TikTok 的帳號、貼文、快照、收藏、比較；Instagram 額外顯示推薦資料數量。
  • 可手動重新整理；統計不會寫入、清理或更動既有資料。
多語系v0.5.122026.07

符合 Chrome 原生多語系設定

依 Chrome i18n 規範加入繁體中文、簡體中文與英文擴充功能中繼資料；名稱、說明與工具列提示可隨 Chrome 介面語言切換，擴充功能內的手動語言切換仍保留。

資料精確度v0.5.112026.07

精確粉絲數優先保留與顯示

Instagram 已載入的 follower_count 可用時，會優先保存精確整數；DOM 顯示的「1.1萬」等縮寫不再覆蓋它。浮窗帳號總計與報告可顯示完整數字。

Chrome 商店公開版本v0.5.102026.07

Instagram 推薦帳號的被動監聽修正

Instagram 可能以 text/javascript 回傳推薦帳號 JSON；本版更新既有回應辨識，並在沒有本機快取時，導向 Instagram 正常的「類似帳號」頁面，讓平台自行載入資料。

  • 僅保存 Instagram 實際提供的帳號、名稱、頭像、驗證與關係狀態。
  • 不推測相似度、粉絲數、ER 或觀看數；沒有平台資料時保持空白。
  • 不建立或重放 GraphQL 請求。
功能擴充v0.5.92026.07

Instagram 相似創作者列表

在 Instagram 浮窗加入「數據分析／推薦網紅」切換，推薦資料獨立保存在本機，不進入貼文統計、快照、比較或匯出。

體驗修正v0.5.8–0.5.72026.07

收藏、指標與介面細節

加入浮窗收藏入口與 Instagram／TikTok 收藏篩選；小於 1% 的 ER／ERR 以小數第二位顯示；補齊收藏頁與設定頁的游標互動。

設定與管理v0.5.6–0.5.52026.07

設定頁、資料備份與收藏帳號

建立版本化 SettingsManager、分析與報告範圍設定、KPI 排序、熱門內容設定、快照策略、快取上限、備份／還原與收藏帳號頁。

  • 匯出檔名可使用平台、帳號、日期與分析範圍變數。
  • 降低快取上限後會立即裁剪本機資料。
  • 恢復預設設定不會刪除既有快照與分析快取。
資料完整度v0.5.4–0.5.22026.07

首屏 Reels、協作貼文與帳號摘要補值

補強 Instagram 首屏已載入資料、Reels 日期／縮圖、協作貼文、帳號貼文數與粉絲數，並在報告和浮窗顯示對應的平台／協作標記。

產品合併v0.5.02026.07

Instagram + TikTok 成為一個擴充功能

以「社群數據分析｜Passive Analytics」統一品牌與入口；兩個平台仍使用獨立解析器、資料庫、報告、歷史與比較資料，保留各自的內容欄位與統計語意。

品牌與首屏資料v0.4.4–0.4.32026.07

更清楚的 Instagram 圖示與首屏 Reels 補值

更新 Instagram 專屬工具列圖示，並將既有被動監聽移至 document_start 的 MAIN world，降低最新首屏 Reels 在資料尚未完整時漏掉日期的機率。

  • 不主動建立或重放 Instagram 請求。
  • 只從平台已載入的回應、頁面狀態與可見內容補回欄位。
Reels 資料完整度v0.4.2–0.4.12026.07

修正缺少日期的 Reel 不應提早結束分析

舊快取中沒有日期的 Reels 不再被當成完整收集；掃描會繼續等待平台已載入的完整資料，並以 shortcode 合併延後出現的 taken_at。

歷史與比較v0.4.02026.07

新增快照、歷史趨勢與多帳號比較

完成分析後可保存本機快照，並在歷史頁查看趨勢；帳號庫與比較頁可在同一平台內使用既有快取或快照，比較多個帳號並匯出 CSV、JSON、Excel 與 PDF。

  • 快照與比較重用同一套統計、中央値與發文頻率計算。
  • 資料保留於瀏覽器本機，沒有新增後端。
最早可驗證紀錄v0.3.3–0.3.02026.07

Instagram 被動分析的基礎版本

建立 Instagram 貼文與 Reels 的被動資料整理、內容範圍分析、KPI、熱門貼文、報告與本機匯出；後續小版本持續補強首屏資料與發佈日期的取得時機。

此頁目前以可驗證的 v0.3.0 為最早版本；更早的未留存版本不會以推測方式補寫。

如何判讀版本狀態？

Chrome 商店公開版本代表目前可由商店安裝的版本；最新功能版本代表已完成並在桌面載入版驗證的更新，會在後續商店更新時一併發佈。所有可用資料仍以平台當下實際載入內容為準。
