LOCAL-FIRST ANALYSIS

把資料留在瀏覽器，把判讀留給你。

這不是後端資料服務。工具只在使用者主動開啟的 Instagram 個人頁面上工作，將已載入的公開頁面內容整理為可比較的統計結果。

  1. 01
    近期內容的整體表現統計貼文與 Reels 數量、讚、留言、觀看、平均值、中位數、ER%、ERR%、發文頻率與熱門內容。
  2. 02
    可控制的本機掃描支援依近期天數或篇數分析；開始、停止、重新分析與排除置頂貼文都在頁面面板中完成。
  3. 03
    詳細報告與匯出切換到完整報告頁，重新計算近 7、14、30 天與最近 10、30 篇；可輸出 CSV、JSON、Excel 或瀏覽器列印 PDF。
  4. 04
    明確的隱私邊界不讀取、保存或上傳 Cookie、Authorization、CSRF Token、Session 或密碼；不把分析資料傳送到外部服務。
01　開啟帳號頁

前往你要檢視的公開 Instagram 個人頁面，面板僅在個人頁顯示。

02　開始整理

選擇最近天數或篇數，讓 Instagram 頁面自行載入內容，工具在本機整理可用欄位。

03　比較與輸出

在緊湊面板看核心數據；需要更完整的時間區間比較時，開啟詳細報告並匯出。

常見問題

為什麼有些 Reels 欄位可能顯示 N/A？

工具只使用 Instagram 當下頁面已載入的公開欄位。若頁面沒有提供特定貼文的讚、留言、觀看或日期，工具會誠實顯示 N/A，不會把缺失值當成 0。

資料儲存在哪裡？

已整理的貼文欄位、快取與面板設定使用瀏覽器本機儲存。可在擴充功能內清除本機分析資料。

工具會主動呼叫 Instagram API 嗎？

不會。它只被動處理目前頁面既有的網路回應與頁面內容，不建立或重放 Instagram 未公開 API 請求。

在不把內容資料交給第三方的前提下，建立你的 Instagram 近期內容基準。

安裝後，直接在 Instagram 個人頁面啟動本機分析。
