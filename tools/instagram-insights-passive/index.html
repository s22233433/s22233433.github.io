START IN FOUR STEPS

讓頁面先載入，
再讓工具替你整理。

工具不需要匯出帳密、貼文清單或 API Key。它只工作在你目前開啟的個人頁面，分析完成後可在本機保留、比較或備份。

  1. 01
    開啟個人頁面

    前往 Instagram、TikTok 或 Threads 想研究的帳號主頁；浮窗會在支援頁面出現。

  2. 02
    選擇分析範圍

    用最近篇數或天數開始分析；頁面自行載入內容，工具只接收當前已載入的資料。

  3. 03
    讀取面板與詳細報告

    先看 KPI、熱門內容與資料來源狀態，再切到報告查看五個可設定的統計範圍。

  4. 04
    保存、比較或匯出

    將帳號加入收藏／比較、保存快照，或匯出 CSV、JSON、Excel 與瀏覽器 PDF。

SETTINGS · AUTO SAVE

設定一改，立即套用。

分析範圍、KPI、快照和快取上限集中管理；所有設定自動保存，不用重開擴充功能。

REPORTS · COMPARE

報告與比較，
都在你的瀏覽器裡完成。

用可配置的範圍閱讀內容趨勢，或將已保存的帳號放入同一張比較表；示意資料均為虛構。

V0.7 · PROJECT WORKSPACE

把創作者名單，
變成可追蹤的專案工作台。

同一位 Instagram、TikTok 或 Threads 創作者可加入多個客戶、活動或提案專案；分類與合作資訊都留在瀏覽器本機。

  1. 01
    集中管理合作資訊

    在專案中查看備註、Email、LINE、WhatsApp、WeChat 與每個專案獨立的合作進度。

  2. 02
    從工作摘要安排下一步

    快速找出缺聯絡資料、資料過期、待更新或需要注意的創作者，再依篩選範圍批量刷新、比較、匯出或備份。

ONE EXTENSION · THREE PLATFORMS

從當前內容，到可回看的決策脈絡。

三個平台共用同一種工作體驗，但資料模型與本機資料庫保持分離，避免同名帳號或不同指標口徑互相污染。

◎

頁內資料分析

近期篇數／天數、置頂排除、KPI 卡、熱門內容、發布頻率與最後發文日期，一次放在可拖曳的浮窗裡。

  • 粉絲與帳號內容總數
  • 讚、留言、觀看、ER、ERR
  • Instagram 協作貼文標記
↗

詳細報告與匯出

以五個可自訂的時間／篇數範圍重算，避免把不同樣本口徑混在同一張表。

  • 趨勢、熱門內容、逐篇明細
  • CSV、JSON、Excel、列印 PDF
  • 可自訂匯出檔名格式
◌

歷史與多帳號比較

把完成分析保存為快照，回看趨勢，並在同一平台內最多比較 10 個已保存帳號。

  • 30 / 90 / 180 天歷史篩選
  • 資料過期與樣本差距提醒
  • 收藏帳號統一管理
⌘

設定、備份與還原

將分析範圍、KPI、熱門內容、快照與快取上限集中設定；每次修改會自動保存。

  • 自訂預設快捷範圍
  • 48 / 96 / 144 / 192 篇快取
  • JSON 備份設定與分析資料

PRIVACY & DATA BOUNDARY

不是資料搬運服務，
也不是自動化帳號。

做的事 被動處理目前頁面已載入的網路回應、頁面狀態與可見 DOM；在本機正規化、計算與保存。

不做的事 不讀取、保存或上傳 Cookie、Token、Session、密碼；不建構、呼叫或重放 Instagram／TikTok／Threads 未公開 API。

資料保存 Instagram、TikTok 與 Threads 分別保存在本機資料庫；可從設定匯出／匯入備份，也可自行清除。
